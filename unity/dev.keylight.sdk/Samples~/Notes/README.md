# Keylight Notes — Sample

This folder is a placeholder for the **Keylight Notes** sample (Task 14).

It will contain a minimal Unity scene that:

- Gates a "Pro" feature behind `HasEntitlement("pro")`

Import this sample via **Window > Package Manager > Keylight > Samples > Keylight Notes**.
